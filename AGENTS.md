# Krishak project asset policy

The following four files are original Manus Krishak assets and are immutable unless the user explicitly requests an image change:

- `client/public/manus-storage/krishak-mark_b9b95f65.webp` — favicon in `client/index.html`
- `client/public/manus-storage/krishak-hub-hero_83017072.webp` — main hub hero, home image stack, and Community hero
- `client/public/manus-storage/krishak-field-detail_05c7e3a9.webp` — home image stack and field-detail feature image
- `client/public/manus-storage/krishak-network-texture_7aee977c.webp` — agricultural footer background texture

Do not replace, crop, modify, regenerate, delete, move, or rename these files. Preserve their component placements and byte hashes recorded in `client/public/manus-storage/IMMUTABLE_ASSETS.sha256` during every future update.
